# Версионирование

Проект использует [Semantic Versioning](https://semver.org/lang/ru/):
`MAJOR.MINOR.PATCH` (например, `1.4.2`).

Версия в `package.json` повышается автоматически при каждом мердже в `main`
воркфлоу `.github/workflows/version-bump.yml`. Тип повышения определяется по
сообщениям коммитов ([Conventional Commits](https://www.conventionalcommits.org/ru/))
с момента последнего тега `vX.Y.Z`.

## Что считается MAJOR (ломающее изменение)

Несовместимые изменения, после которых старые данные/поведение могут
перестать работать без ручных действий пользователя: несовместимая миграция
схемы Dexie/IndexedDB, изменение формата backup/restore, удаление или
несовместимое изменение публичного поведения экрана/фичи.

Коммит помечается так:
- `feat!: ...` или `fix!: ...` (`!` после типа), либо
- в теле коммита есть строка `BREAKING CHANGE: ...`

## Что считается MINOR (новая функциональность)

Обратно совместимые новые фичи и заметные улучшения, не ломающие
существующие данные и поведение (новый экран, новый тип тренировки,
новая настройка и т.п.).

Коммит начинается с `feat: ...` (или `feat(scope): ...`).

## Что считается PATCH (фикс)

Обратно совместимые исправления багов, без изменения публичного поведения.

Коммит начинается с `fix: ...` (или `fix(scope): ...`).

## Что НЕ повышает версию

Коммиты `chore:`, `docs:`, `style:`, `refactor:`, `test:`, `ci:`, `build:`
без пометки `!` и без `BREAKING CHANGE:` — версия не меняется.

## Как это работает технически

1. При пуше в `main` воркфлоу смотрит все коммиты со времени последнего
   тега `vX.Y.Z`.
2. Если среди них есть хотя бы один "ломающий" — версия повышается MAJOR.
   Иначе, если есть хотя бы один `feat:` — MINOR. Иначе, если есть хотя бы
   один `fix:` — PATCH. Иначе версия не меняется.
3. Воркфлоу выполняет `npm version <major|minor|patch> --no-git-tag-version`,
   коммитит `package.json`/`package-lock.json` с сообщением
   `chore(release): vX.Y.Z [skip ci]` и создаёт git-тег `vX.Y.Z`.

Пометка `[skip ci]` нужна, чтобы коммит с повышением версии не запускал
воркфлоу сборки и не зациклил сам себя.
